# Agent instructions

This repository is a disposable coding demo.

- Use pnpm.
- Keep the app small. Use browser features before you add a package.
- Change only what the user requests.
- Keep the app available on port 3000.
- Keep the task data in browser storage unless the user asks for another store.
- Run `pnpm check` after you change the app.
- Do not commit or push unless the user asks.

The page is in `index.html`. App logic is in `src/main.js`. Styles are in `src/styles.css`.
